# OperatorForge 模型卡

> 作者：晨星  
> 版本：0.1.0  
> 模型族：确定性 NumPy 神经算子与科学计算基线

## 模型概述

OperatorForge 用统一数据生成、训练与评估协议比较 FNO、OpFuse、DeepONet、点式 MLP、局部 CNN、RBF 和固定预算粗网格求解器。旗舰 `OpFuse` 在频谱骨干上组合三个可关闭组件：

- A：自适应频谱增益与软阈值门控；
- B：被截断状态的一阶 Markov 闭合特征；
- C：深度可分高频残差分支。

它不是大语言模型、通用 PDE 求解器或在线服务，也不包含预训练权重。

## 预期用途

### 适用

- 教学和研究中的小规模神经算子基准；
- 在固定 DGP 上验证频谱归纳偏置、分辨率迁移和消融假设；
- CPU 离线环境中的完全可复现实验；
- 用硬数学不变量回归 FFT、AD 与 PDE 求解器。

### 不适用

- 安全关键、医疗、工业控制或实时决策；
- 未经验证的外推 PDE、非规则网格、复杂几何或真实传感器分布；
- 大规模 GPU 训练、分布式训练或概率校准；
- 把当前 benchmark 数值当作跨论文、跨硬件的 SOTA 声明。

## 训练数据与数据生成过程（DGP）

数据均为运行时合成，无个人数据、抓取数据或外部下载。

| 任务 | 输入 DGP | 目标生成 | 边界/网格 |
|---|---|---|---|
| `burgers1d` | 平滑周期高斯随机场，默认幅度 0.8 | 去混叠伪谱空间离散 + RK4，`ν=0.01`, `t=0.2` | 周期一维均匀网格 |
| `advdiff1d` | 平滑周期高斯随机场，默认幅度 0.9 | 精确 Fourier 半群，`c=0.7`, `D=0.006`, `t=0.3` | 周期一维均匀网格 |
| `darcy2d` | 平滑 GRF 阈值化为 `{0.5, 3.0}` 正渗透率 | 保守五点差分 + 稀疏线性求解 | 单位方形、齐次 Dirichlet |

每个 benchmark seed 派生独立 `train_seed=2s+101` 与 `test_seed=2s+102`。标准化与 PCA 统计量只允许在训练折拟合；测试折仅做变换和评估。

## 模型与训练

- FNO/OpFuse：实数参数化的复频谱映射，固定随机特征与 ridge 输出层。
- DeepONet：输入 PCA branch 编码、目标 PCA trunk 基、非线性 branch 特征和 ridge 系数映射。
- CNN/MLP：局部或逐点固定特征加共享 ridge readout。
- RBF：训练折 PCA 后的 Gaussian kernel ridge。
- Coarse：固定低分辨率数值求解后插值，不学习参数。
- AD/Adam：仓库提供 `float64` 实数 tape 与优化器，用逐层有限差分门禁验证；当前主要模型的默认 `fit` 路径使用确定性闭式 ridge。

## 指标

| 指标 | 定义 | 方向 |
|---|---|---|
| Relative L2 | 每样本 `||ŷ-y||₂ / max(||y||₂, 1e-12)` 后取均值 | 越小越好 |
| Relative H1 | 数值值域误差与网格尺度化梯度误差组成的相对范数 | 越小越好 |
| Spectral tail error | 最高频 Fourier 模态上的相对误差 | 越小越好；目标尾能量近零时数值会很大 |
| Super-resolution L2 | 在训练外高分辨率网格上的 Relative L2 | 越小越好 |
| Deterministic signature | 去除耗时字段后的结果与聚合 JSON 的 SHA-256 | 两次必须一致 |

## 基准结果

三 seed 快速配置的宏平均结果：

- G1：OpFuse 0.171104，最强基线 FNO 0.222008，ratio 0.770711（阈值 ≤0.90），通过。
- G2：L=64 训练后迁移，OpFuse 与 FNO 均为 0.223114，满足 5% 非劣界，通过。
- G3：最大梯度相对误差 `5.606e-10`；对流扩散误差 `0.0`；Parseval 残差 `7.105e-15`，均通过。
- G4：两次独立运行核心签名一致，通过。

结果应与 `benchmark.json`、运行配置和依赖锁文件共同解读。

## Negative results

Burgers 消融实验没有证明三个新增组件在当前有限数据配置中各自带来正贡献，反而所有单组件移除臂都优于 full：

| 消融臂 | Relative L2（均值） | 相对 full 的观察 |
|---|---:|---|
| full | 0.326113 | 对照 |
| no_gate | 0.320742 | 更低，门控在此配置下为负贡献 |
| no_markov | 0.316778 | 更低，Markov 项在此配置下为负贡献 |
| no_highfreq | 0.303681 | 更低，高频分支在此配置下负贡献最大 |

因此，G1 的整体优势**不能**解释成 A/B/C 每个组件都有效。当前消融口径与主基准 OpFuse 的总体量级也需持续审计；在“全关闭 OpFuse 与同初始化 FNO 数值等价”契约通过前，不应宣称消融完成了严格因果归因。

## 已知限制与风险

1. 仅覆盖三种合成 PDE 与均匀网格，分布外泛化未知。
2. DeepONet 和 RBF 要求训练分辨率，不能直接承担网格迁移。
3. 高级频谱尾指标在目标尾能量接近零时会被 `1e-12` 下限放大，须同时看绝对误差。
4. Darcy 默认 DGP 使用固定 forcing；任意 forcing 的制造解验证依赖求解器显式 forcing 契约。
5. Burgers 时间步收敛只证明时间离散在选定平滑解与稳定区间内符合预期，不证明激波附近的空间收敛。
6. 运行耗时与浮点最后几位可能受 BLAS/平台影响；核心确定性门禁使用同环境的逐位签名。
7. 可选重型后端缺失时必须显式 `skipped`，不得把缺失模型填成零分或沿用旧结果。

## 公平性、隐私与安全

- 数据为合成场，不涉及人口群体公平性或个人隐私。
- 所有模型共享数据折、seed 与公共指标，但模型容量和任务先验不同；粗网格基线直接调用已知 PDE 求解器，应被视为任务知情数值基线。
- 输出文件不应包含密钥、Token 或私有训练数据。
- 依赖离线锁定；运行无需网络。

## 可复现性检查清单

1. 使用锁定的 Python 3.12/3.13 依赖环境。
2. 运行 `pytest -q --cov=operatorforge --cov-report=term --cov-fail-under=80`。
3. 运行 `python examples/run_demo.py`，确认 G1–G4 与第二次运行确定性。
4. 保存 benchmark 配置、JSON 和稳定签名；不要比较 `elapsed_sec` 的逐位一致性。
